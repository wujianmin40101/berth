# 泊位

泊位是一个 macOS 应用，用来管理本机的开发环境。它可以给 Node.js、Python、Go、Java 和 Rust 停靠版本，也可以查看端口、进程、本机磁盘和内存。

窗口、程序坞和侧栏上的名字是泊位。应用文件是 `泊位.app`。里面的可执行文件、工程目标和本机数据目录仍叫 MacBJ。

## 主要功能

### 版本

给五种运行时查看、安装、切换和卸载版本。

- Node.js 按顺序识别 fnm、nvm、Volta。都没有时，只显示当前 `node -v`，不能切换。
- Python 按顺序识别 pyenv、uv。都没有时，只显示当前 `python3 --version`，不能切换。
- Go、Java、Rust 使用官方安装包。Java 来自 Eclipse Temurin。
- 可以设成新开终端使用的全局默认，也可以把版本写进项目目录。
- 进入带有 `.nvmrc`、`.node-version` 或 `.python-version` 的目录时，终端钩子会切到对应版本。离开后回到全局默认。

这里的「默认」是新开一个终端会用的版本，不是已经打开的终端里临时切过的结果。

### 项目

把常用项目留在列表里，查看目录里写好的版本，并从这个目录启动本地服务。

### 工具箱

- **端口**：读取正在监听的 TCP 端口。结束进程前会确认，不会结束泊位自己。
- **进程**：只列出 Node 和 Python，显示内存占用。结束时会连同它拉起的子进程一起结束。
- **本地服务**：在指定目录用登录 shell 启动命令，并查看输出。可以注入钥匙串变量和已保存的代理。退出泊位时，会结束这里启动的服务和它的子进程。
- **Hosts**：读取和编辑本机 `/etc/hosts`。写入前会校验，必须保留 localhost，并先做备份。确认时会弹出系统密码框。
- **密钥**：变量存在系统钥匙串里，不写入 `~/.zshrc`。钥匙串拒绝保存时，页面会写明原因。
- **Git**：修改全局用户名、邮箱、`http.proxy` 和别名。已有的 `~/.ssh/id_ed25519.pub` 不会被覆盖。
- **代理**：只保存你自己填写的地址，不修改 shell 配置，也不修改系统网络代理。空着的项不会注入本地服务。
- **命令收藏**：把命令留在本机。运行时使用登录 shell，超时后结束。
- **格式工具**：在本机做 JSON 美化或压缩、Unix 时间戳转换，以及 Base64 和 URL 编解码。剪贴板只在点按钮时读取。

端口、进程和本地服务第一次打开工具箱时就启用。其余工具可以在工具箱里单独打开。

### 本机

- **内存分布**：按活动监视器的口径分成应用内存、联动内存、已压缩、缓存文件和可用。可以在条形图和环形图之间切换。退出应用前会确认，不能从这里退出系统进程和泊位。
- **卸载应用**：把应用移到废纸篓，并带走用户资源库里只属于它的偏好、缓存和支持文件。和别的应用共用的文件会留下。系统应用和泊位不能卸载。
- **清理缓存**：只清理可以重新生成的缓存、日志和废纸篓。个人文件不在列表里。
- **启动磁盘**：用矩形树图按目录看实际占用。点一块可以进入下一级。各项加起来不一定等于磁盘已用空间。
- **优化速度**：释放未使用的内存、刷新 DNS、结束占资源的进程，以及开关当前用户的启动代理。释放内存和刷新 DNS 会弹出系统密码框。

每个功能标题旁都有问号，点开可以看到它实际会做什么。

## 环境

- macOS 15 或更高版本
- 构建需要 Xcode
- 应用没有打开 App Sandbox。它要运行本机的版本管理器，并读取用户目录里的配置

## 构建

用 Xcode 打开 `MacBJ.xcodeproj`，或在项目目录执行：

```sh
xcodebuild -project MacBJ.xcodeproj -scheme MacBJ -destination 'platform=macOS' build test
```

## 安装

打开 `泊位.app` 即可使用。

当前安装包只做了本机临时签名，没有经过 Apple 公证。别人从网络下载后打开，系统可能会拦住，并提示无法验证是否安全。这时请到「系统设置 → 隐私与安全性」里手动允许。
